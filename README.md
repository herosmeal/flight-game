Sky Courier — an original 2D flight game. Fly a courier aircraft through a sequence of target rings over a seeded valley of patchwork fields, a winding river and hills, mind your fuel, then land on runway 09 to complete the mission. Three missions with different goals, lit instruments (altitude, speed, heading), synthesised engine and chime sounds, and deterministic seeded worlds.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests — everything is static files under `game/`.
